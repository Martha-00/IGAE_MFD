# IGAE_MFD
Este repositorio presenta un análisis del Modelo de Factores Dinámicos (MFD) aplicado a los datos del Indicador Global de la Actividad Económica (IGAE), compuesto por 14 series de tiempo. Este trabajo fue desarrollado como parte del curso de Series de Tiempo durante la maestría.

## Objetivo del análisis

El propósito principal es modelar la estructura común entre las series temporales del IGAE mediante un enfoque de factores dinámicos. Las etapas del análisis incluyeron:

1. Análisis exploratorio del conjunto de series.
2. Pruebas de raíces unitarias individuales.
3. Determinación del número de factores.
4. Estimación de los componentes (matriz de pesos, factores y errores idiosincráticos) utilizando Componentes Principales (CP).
5. Interpretación de los resultados y evaluación de su consistencia.

## Contenido del repositorio

1. `IGAE_MFD.RMD`: archivo principal en R Markdown, donde se desarrolla el modelo.
2. `IGAE_MFD.pdf`: versión en PDF del archivo anterior, lista para consulta o difusión.
3. `functions.R`: archivo en R que contiene funciones que se utilizaron durante el desarrollo del modelo.
4. `IGAE`: base de datos con las 14 series temporales que conforman al IGAE, descargadas del portal de INEGI.
5. `CIMAT_INEGI.png`: logotipo institucional del INEGI y CIMAT utilizado en el documento.
